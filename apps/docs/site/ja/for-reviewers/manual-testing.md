# 手動テスト

自動テスト（Playwright の E2E）は、偽の YouTube ページを使って Chromium だけで動かしています。
このページでは、**自動テストでは確かめられないこと**を人の手で確認します。

- 本物の YouTube での表示（ページ構成の変化、ダークモード、シアターモードなど）
- Firefox での動作
- 英語・日本語・韓国語の表示
- インストール・アップデート時の権限の表示

## テスト用ビルドの入手

ビルド環境は不要です。プルリクエストまたは main への push ごとに、CI がテスト用の zip を作ります。

1. GitHub の **Actions** タブで、対象のプルリクエスト（またはコミット）の **CI** の実行を開く
2. ページ下部の **Artifacts** から `extension-<コミット>` をダウンロードして解凍する
3. 中にある `*-chrome.zip` / `*-firefox.zip` を使う

### Chrome に読み込む

1. `*-chrome.zip` を解凍する
2. `chrome://extensions/` を開き、右上の **デベロッパーモード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** で、解凍したフォルダを選ぶ

### Firefox に読み込む

1. `about:debugging#/runtime/this-firefox` を開く
2. **一時的なアドオンを読み込む** で `*-firefox.zip` を選ぶ（解凍不要）

> [!NOTE]
> Firefox の一時的なアドオンは、Firefox を再起動すると消えます。

## 結果の記録

- プルリクエストの説明欄にある「手動テスト」のチェックリストに、確認した項目と環境（OS・ブラウザのバージョン）を書いてください。
- 問題を見つけたら、項目の ID（例: `C-3`）、手順、期待した結果、実際の結果、スクリーンショットを Issue に書いてください。
- 各項目の確認中は、ブラウザの開発者ツールの **コンソールに拡張機能のエラーが出ていないか** も見てください。

## 確認する環境

最低限、次の 2 つで全項目を確認します。

| 環境 | 備考 |
| :--- | :--- |
| Chrome（最新版） | |
| Firefox（最新版） | 自動テストの対象外なので特に重要 |

余裕があれば Edge、Brave、Firefox ESR でも確認してください。

## チェックリスト

### A. インストールと権限

| ID | 手順 | 期待する結果 |
| :--- | :--- | :--- |
| A-1 | 拡張機能を新しく読み込む | エラーなく読み込まれる。ツールバーにアイコンが出る |
| A-2 | 拡張機能の詳細画面で権限を見る | 要求している権限は「タブ（閲覧履歴の読み取り）」と YouTube サイトへのアクセスだけ。「ストレージ」は無い |
| A-3 | ストア版（v4.0.1）を入れた状態から、テスト用ビルドに更新する（Chrome は同じフォルダを上書き → 再読み込み） | 新しい権限の確認が出ない。更新後も正しく動く |

### B. 視聴ページのサムネイル（本物の YouTube）

| ID | 手順 | 期待する結果 |
| :--- | :--- | :--- |
| B-1 | 通常の動画の視聴ページ（`youtube.com/watch?v=...`）を開く | チャンネルアイコンの左にサムネイルが出る。レイアウトが崩れない |
| B-2 | サムネイルにマウスを乗せる | 1.75 倍に拡大し、上に「全サイズのサムネイルを見る」と出る。周りの要素は動かない |
| B-3 | サムネイルをクリックする | 新しいタブで Thumbnail View が開き、その動画が表示される |
| B-4 | 関連動画をクリックして別の動画に移る（ページの再読み込みなし） | サムネイルが新しい動画のものに変わる。サムネイルが 2 つ並ばない |
| B-5 | ブラウザの「戻る」「進む」で動画を行き来する | 毎回その動画のサムネイルになる |
| B-6 | 古い動画（2010 年以前など、高解像度サムネイルが無いもの）を開く | 灰色の画像ではなく、その動画の画像が出る（画質は低くてよい） |
| B-7 | YouTube をダークテーマにして B-1 / B-2 を確認する | 見た目に問題がない |
| B-8 | シアターモード・全画面表示を切り替える | サムネイルや動画プレーヤーの表示が崩れない |
| B-9 | ライブ配信・プレミア公開の視聴ページを開く | サムネイルが出る。エラーが出ない |
| B-10 | ホーム・検索結果・チャンネルページを開く | サムネイルは差し込まれない。エラーが出ない |
| B-11 | 視聴ページを 10 分ほど操作する（スクロール、コメント表示、関連動画の移動） | 重くならない |

### E. 表示言語

| ID | 手順 | 期待する結果 |
| :--- | :--- | :--- |
