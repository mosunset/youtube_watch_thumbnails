## 機能

| 機能 | 説明 |
| :--- | :--- |
| **ワンクリックで表示** | ブラウザのツールバーアイコンをクリックするだけで、現在再生中の動画のサムネイルを即座に表示できます。 |
| **全サイズ・全フォーマットに対応** | 最大画質 (maxresdefault) から低画質まで、全解像度・全フォーマット（JPG/WebP）を一覧で確認・ダウンロード可能。 |
| **Shorts 対応** | 通常の動画だけでなく、YouTube Shorts のサムネイル取得にも対応しています。 |
| **ページ統合** | YouTube の視聴ページに直接サムネイルを表示。クリック一発で詳細画面へ移動できます。 |
