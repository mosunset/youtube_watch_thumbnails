# プライバシーポリシー

最終更新日: 2026年11月7日

## データ収集について

YouTube Watch Thumbnails（以下「本拡張機能」）は、ユーザーのプライバシーを最優先に考えて設計されています。

### 収集・保存するデータ

**本拡張機能は、データを一切保存しません。**

`chrome.storage` / `browser.storage`、Cookie、その他のブラウザストレージは使用していません。設定項目や履歴もありません。表示中の動画 ID は Thumbnail View タブの URL（`ThumbnailView.html?v=動画ID`）で受け渡すだけで、タブを閉じれば残りません。

- **外部サーバーへの送信**: 一切行いません
- **保存**: デバイスには何も書き込みません
- **第三者アクセス**: 不可能

### 収集しないデータ

本拡張機能は、以下のデータを収集・保存しません：

- ログイン情報やパスワード
- 閲覧履歴（YouTube 内外を問わず）
- 個人を特定できる情報（氏名、メールアドレスなど）
- 使用状況の統計やアナリティクス

## 情報の使い方

本拡張機能は、動画 ID を取り出すためだけに表示中の YouTube タブの URL を読み取り、メモリ上でサムネイル画像の URL を組み立てます。

サムネイル画像は YouTube の公開画像サーバー（`i.ytimg.com` / `img.youtube.com`）から直接読み込み、ブラウザ上に表示します。

## データの共有

**本拡張機能は、第三者とデータを共有することは一切ありません。** そもそもデータを保存しないため、共有するものがありません。

## データの削除

削除が必要な保存データはありません。Thumbnail View タブを閉じる、または拡張機能をアンインストールすれば、何も残りません。

## 権限について

本拡張機能が要求する権限とその理由：

| 権限 | 理由 |
|------|------|
| `tabs` | ポップアップで表示中のタブの URL を読み取り、YouTube の動画 ID を取り出すため |

## セキュリティ

本拡張機能は、以下のセキュリティ対策を実施しています：

- すべての通信は HTTPS（暗号化された通信）のみを使用
- 外部への通信は YouTube の公開 API のみに制限
- オープンソースとして公開し、コードの透明性を確保

## 子供のプライバシー

本拡張機能は、13歳未満の子供を対象としていません。また、年齢に関わらず個人データを収集することはありません。

## 変更の通知

このプライバシーポリシーを変更する場合、拡張機能のアップデート時に通知します。
