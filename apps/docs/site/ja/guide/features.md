# 機能

## 主な機能

### 視聴ページのサムネイル表示
YouTube の視聴ページで、チャンネル名の左にその動画のサムネイルを表示します。ページを再読み込みせずに別の動画へ移っても、サムネイルが切り替わります。

### ホバー拡大
サムネイルにマウスを乗せると拡大表示（1.75 倍）されます。詳細ビューを開かずに画像の内容を素早く確認できます。

### Thumbnail View（全サイズ一覧）
サムネイル、またはポップアップの画像をクリックすると、新しいタブで Thumbnail View が開きます。YouTube がその動画に用意しているサムネイル（19 種類のファイル名 × WebP / JPG × `i.ytimg.com` / `img.youtube.com`）を一覧表示します。選んだ画像をプレビューし、実際のサイズを確認して、ファイルの URL を開いたり、右クリックで保存したりできます。タブごとに別の動画を表示でき、再読み込みしても内容は変わりません。

### ポップアップ
視聴ページや Shorts で拡張機能のアイコンをクリックすると、その動画で一番画質の高いサムネイルを表示します。それ以外のページでは、使える場所を案内します。

### 一番きれいな画像を自動で選ぶ
実際に存在するサイズを確かめ、YouTube の灰色の「サムネイルなし」画像は除外します。古い動画でも、その動画の一番きれいな画像が表示されます。

### 表示言語
ポップアップ、Thumbnail View、ページ上のツールチップは、ブラウザの言語に合わせて英語・日本語・韓国語で表示されます。

## ブラウザによる違い

Chrome、Firefox など対応しているブラウザで、機能は同じです。
