# 設定

現在、この拡張機能には**設定項目がなく**、オプションページもありません。インストールしたままの状態で動作します。

- **サムネイルの画質**: 実際に存在する最も高画質なサムネイルを自動で選びます。すべての候補（`maxresdefault`、`hq720`、`sddefault` など、WebP と JPG）を並列で確認し、YouTube の 120 × 90 のプレースホルダー画像は除外します。
- **表示言語**: ポップアップ、ページ上のツールチップ、Thumbnail View はブラウザの言語に合わせて表示されます（英語・日本語・韓国語に対応。それ以外の言語では英語で表示）。
- **キーボードショートカット**: ブラウザが対応していれば、拡張機能のショートカット設定から割り当てられます。

設定がないため、拡張機能はデータを一切保存しません。詳しくは[プライバシーポリシー](/ja/resources/privacy)をご覧ください。
