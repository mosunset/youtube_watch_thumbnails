# YouTube Watch Thumbnails

**View and download video thumbnails instantly**

## Features

| Feature | Description |
| :--- | :--- |
| **One-Click Display** | Click the toolbar icon to instantly display thumbnails of the currently playing video. |
| **All Sizes & Formats** | View and download all resolutions (from maxresdefault to low quality) and formats (JPG/WebP) in one place. |
| **Shorts Support** | Works with both regular YouTube videos and YouTube Shorts. |
| **Page Integration** | Thumbnails are directly displayed on YouTube video pages. One click to open the detailed view. |
