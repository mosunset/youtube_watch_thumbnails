# Settings

The extension currently has **no settings** and no options page. It works out of the box:

- **Thumbnail quality**: The highest-quality thumbnail that actually exists is chosen automatically. All candidates (`maxresdefault`, `hq720`, `sddefault`, …, in WebP and JPG) are checked in parallel, and YouTube's 120 × 90 placeholder images are ignored.
- **Language**: The popup, the on-page tooltip and Thumbnail View follow your browser's language (English, Japanese and Korean are supported; other languages fall back to English).
- **Keyboard shortcuts**: You can assign one from your browser's extension shortcut settings if supported.

Because there are no settings, the extension stores no data. See the [Privacy Policy](/resources/privacy) for details.
