## General Settings

### Prioritize High Quality Thumbnails
- **Description**: When enabled, the extension will always try to fetch the `maxresdefault` thumbnail first.
- **Default**: Enabled
- **Behavior**: If `maxresdefault` is not found (404), it automatically falls back to the next best quality (`sddefault`, etc.).

### Show on Search Results
- **Description**: Toggle whether thumbnails should appear next to videos in search results.
- **Default**: Enabled

### Show on Home Page
- **Description**: Toggle whether thumbnails should appear on the YouTube home page.
- **Default**: Enabled
