## Installing on Chrome

### From Chrome Web Store

1. Visit the [Chrome Web Store](https://chrome.google.com/webstore)
2. Search for "YouTube Watch Thumbnails"
3. Click **[Add to Chrome]**
4. Click **[Add extension]** in the confirmation dialog

### From GitHub Release (Offline)

For development versions or offline environments:

1. Download the latest `.zip` file from [GitHub Releases](https://github.com/mosunset/youtube_watch_thumbnails/releases)
2. Extract the downloaded file
3. Open `chrome://extensions/` in Chrome
4. Enable **[Developer mode]** in the top right
5. Click **[Load unpacked]**
6. Select the extracted folder

## Installing on Firefox

### From Firefox Add-ons

1. Visit [Firefox Add-ons](https://addons.mozilla.org/)
2. Search for "YouTube Watch Thumbnails"
3. Click **[Add to Firefox]**
4. Click **[Add]** in the confirmation dialog

### From GitHub Release (Offline)

1. Download the latest `.xpi` file from [GitHub Releases](https://github.com/mosunset/youtube_watch_thumbnails/releases)
2. Open `about:addons` in Firefox
3. Click the gear icon ⚙️
4. Select **[Install Add-on From File]**
5. Select the downloaded `.xpi` file

## Verification

After installation:

1. Visit YouTube
2. Verify that the extension icon appears in your browser toolbar
3. Click the icon to confirm it's working
