## Core Features

### Thumbnail Display
The extension automatically detects the video ID on YouTube watch pages and Shorts, and fetches the corresponding thumbnail.

### Hover Zoom
Hover over the thumbnail to see an enlarged version. This allows for a quick inspection of the image details without opening the full view.

### Copy Thumbnail URL
You can easily copy the URL of the displayed thumbnail to your clipboard.
