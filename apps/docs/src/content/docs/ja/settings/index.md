## 一般設定

### 高品質サムネイルを優先
- **説明**: 有効にすると、拡張機能は常に `maxresdefault` サムネイルを最初に取得しようとします。
- **デフォルト**: 有効
- **挙動**: `maxresdefault` が見つからない（404）場合、自動的に次に画質の良いもの（`sddefault` など）にフォールバックします。

### 検索結果に表示
- **説明**: 検索結果の動画の横にサムネイルを表示するかどうかを切り替えます。
- **デフォルト**: 有効

### ホーム画面に表示
- **説明**: YouTube のホーム画面にサムネイルを表示するかどうかを切り替えます。
- **デフォルト**: 有効
