## 主な機能

### サムネイル表示
YouTube の視聴ページや Shorts で動画 ID を自動検出し、対応するサムネイルを取得して表示します。

### ホバー拡大
サムネイル画像にマウスを合わせると拡大表示されます。詳細ビューを開かずに画像の内容を素早く確認できます。

### サムネイル URL のコピー
表示されているサムネイルの URL を簡単にクリップボードにコピーできます。
