## 権限 (Permissions)

- `storage`: ユーザー設定（サムネイル画質設定など）を保存するために使用します。
- `activeTab`: 現在のタブの URL にアクセスして動画 ID を抽出するために使用します。
- `scripting`: コンテンツスクリプトを注入するために使用します。

## データプライバシー

- この拡張機能は、ユーザーデータを外部サーバーに収集または送信**しません**。
- すべての処理はブラウザ内でローカルに行われます。
- 設定はローカルストレージに保存されます。

## セキュリティ

- コンテンツセキュリティポリシー (CSP) は厳格に適用されています。
- リモートコード実行はありません。
