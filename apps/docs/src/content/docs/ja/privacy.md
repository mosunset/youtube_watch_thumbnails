## データ収集について

YouTube Watch Thumbnails（以下「本拡張機能」）は、ユーザーのプライバシーを最優先に考えて設計されています。

### 収集・保存するデータ

本拡張機能は、以下のデータをブラウザのローカルストレージに保存します：

- **動画ID**: サムネイルを表示した YouTube 動画の ID（文字列）
- **拡張機能の設定**: ユーザーが行った設定（文字列）

### データの保存場所

すべてのデータは、ブラウザのローカルストレージ（`chrome.storage.local` または `browser.storage.local`）に保存されます。

- **外部サーバーへの送信**: 一切行いません
- **保存場所**: ユーザーのデバイス内のみ
- **第三者アクセス**: 不可能

### 収集しないデータ

本拡張機能は、以下のデータを収集・保存しません：

- ログイン情報やパスワード
- YouTube 以外のブラウジング履歴
- 個人を特定できる情報（氏名、メールアドレスなど）
- 使用状況の統計やアナリティクス

## データの使用目的

保存したデータは、以下の目的でのみ使用されます：

1. **動画ID**: 最近表示したサムネイルの履歴管理
2. **設定**: ユーザーの設定を保持し、次回使用時に復元

YouTube の公開 API からサムネイル情報を取得し、ブラウザ上に表示します。

## データの共有

**本拡張機能は、保存したデータを第三者と共有することは一切ありません。**

すべてのデータはローカルに保存され、外部への送信は行われません。

## データの削除

ユーザーは、いつでも以下の方法でデータを削除できます：

### ブラウザのストレージをクリア

ブラウザの設定から、拡張機能のストレージデータを削除できます。

### 拡張機能をアンインストール

拡張機能をアンインストールすると、保存されているすべてのデータが自動的に削除されます。

## 権限について

本拡張機能が要求する権限とその理由：

| 権限 | 理由 |
|------|------|
| `tabs` | YouTube のタブ情報を取得し、動画情報にアクセスするため |
| `storage` | 拡張機能の設定を保存するため |

## セキュリティ

本拡張機能は、以下のセキュリティ対策を実施しています：

- すべての通信は HTTPS（暗号化された通信）のみを使用
- 外部への通信は YouTube の公開 API のみに制限
- オープンソースとして公開し、コードの透明性を確保

## 子供のプライバシー

本拡張機能は、13歳未満の子供を対象としていません。また、年齢に関わらず個人データを収集することはありません。

## 変更の通知

このプライバシーポリシーを変更する場合、拡張機能のアップデート時に通知します。
