# Privacy Policy

Last Updated: November 24, 2024

## About Data Collection

YouTube Watch Thumbnails (the "Extension") is designed with user privacy as the top priority.

### Data We Collect and Store

This extension stores the following data in your browser's local storage:

- **Video IDs**: YouTube video IDs for which thumbnails have been displayed (string)
- **Extension Settings**: User configuration settings (string)

### Data Storage Location

All data is stored in your browser's local storage (`chrome.storage.local` or `browser.storage.local`).

- **No external server transmission**: Never sent to external servers
- **Storage location**: Only on your device
- **Third-party access**: Impossible

### Data We Don't Collect

This extension does NOT collect or store:

- Login credentials or passwords
- Browsing history outside of YouTube
- Personally identifiable information (name, email address, etc.)
- Usage statistics or analytics

## Purpose of Data Usage

Stored data is used solely for:

1. **Video IDs**: Managing history of recently displayed thumbnails
2. **Settings**: Preserving user settings and restoring them on next use

Thumbnail information is fetched from YouTube's public API and displayed in your browser.

## Data Sharing

**This extension does NOT share stored data with any third parties.**

All data is stored locally and is never transmitted externally.

## Data Deletion

Users can delete their data at any time using the following methods:

### Clear Browser Storage

You can delete the extension's storage data from your browser settings.

### Uninstall Extension

Uninstalling the extension automatically deletes all stored data.

## About Permissions

Permissions requested by the Extension and their purposes:

| Permission | Reason |
|------------|--------|
| `tabs` | To get YouTube tab information and access video information |
| `storage` | To store extension settings |

## Security

The Extension implements the following security measures:

- All communication uses HTTPS (encrypted communication) only
- External communication is limited to YouTube's public API only
- Published as open source to ensure code transparency

## Children's Privacy

The Extension is not directed at children under 13. It does not collect personal data from anyone, regardless of age.

## Change Notifications

If we change this Privacy Policy, we will notify users via extension updates.
