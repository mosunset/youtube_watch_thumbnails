# インストール

## Chrome へのインストール

### Chrome Web Store から

1. [Chrome Web Store](https://chrome.google.com/webstore) にアクセス
2. "YouTube Watch Thumbnails" を検索
3. **[Chrome に追加]** をクリック
4. 確認ダイアログで **[拡張機能を追加]** をクリック

### GitHub リリースから（オフライン）

開発版やオフライン環境での使用を希望する場合：

1. [GitHub Releases](https://github.com/mosunset/youtube_watch_thumbnails/releases) から最新版の `.zip` ファイルをダウンロード
2. ダウンロードしたファイルを解凍
3. Chrome で `chrome://extensions/` を開く
4. 右上の **[デベロッパーモード]** を有効にする
5. **[パッケージ化されていない拡張機能を読み込む]** をクリック
6. 解凍したフォルダを選択

## Firefox へのインストール

### Firefox Add-ons から

1. [Firefox Add-ons](https://addons.mozilla.org/) にアクセス
2. "YouTube Watch Thumbnails" を検索
3. **[Firefox へ追加]** をクリック
4. 確認ダイアログで **[追加]** をクリック

### GitHub リリースから（オフライン）

1. [GitHub Releases](https://github.com/mosunset/youtube_watch_thumbnails/releases) から最新版の `.xpi` ファイルをダウンロード
2. Firefox で `about:addons` を開く
3. 歯車アイコン ⚙️ をクリック
4. **[ファイルからアドオンをインストール]** を選択
5. ダウンロードした `.xpi` ファイルを選択

## 動作確認

インストールが完了したら：

1. YouTube にアクセス
2. ブラウザのツールバーに拡張機能のアイコンが表示されることを確認
3. アイコンをクリックして動作を確認
