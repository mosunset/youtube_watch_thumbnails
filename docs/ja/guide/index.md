# 使い方

## 基本的な使い方

### ツールバーアイコンから表示

1. YouTube で動画を再生
2. ブラウザのツールバーにある拡張機能アイコンをクリック
3. 現在再生中の動画のサムネイルがポップアップで表示されます

### YouTube ページ上で表示

YouTube の視聴ページ（チャンネルアイコンの横）に、サムネイル画像が自動的に追加表示されます。

- サムネイル画像をクリックすると、詳細確認画面（Thumbnail View）が開きます

## Thumbnail View（詳細表示）

### 全サイズ・全フォーマットの一覧表示

「Thumbnail View」タブでは、その動画のサムネイルを網羅的に確認できます：

#### 解像度（サイズ）

- **maxresdefault**: 最大画質（1280x720 または 1920x1080）
- **sddefault**: 標準画質（640x480）
- **hqdefault**: 高画質（480x360）
- **mqdefault**: 中画質（320x180）
- **default**: 低画質（120x90）

#### フォーマット

- **JPG**: JPEG 形式
- **WebP**: WebP 形式

### サムネイルのダウンロード

1. Thumbnail View で目的のサムネイルを選択
2. 画像を右クリック
3. **名前を付けて画像を保存** を選択

または、画像をクリックして新しいタブで開き、そこから保存することもできます。

## YouTube Shorts への対応

通常の動画と同じ操作で、YouTube Shorts のサムネイルも取得できます：

1. Shorts を再生
2. ツールバーアイコンをクリック、またはページ上のサムネイルをクリック
3. Shorts のサムネイルが表示されます

## 活用例

### クリエイター向け

- 自分の動画のサムネイルを確認
- 競合チャンネルのサムネイルデザインを研究
- 全解像度でのサムネイル表示を確認

### 一般ユーザー向け

- 気に入った動画のサムネイルを保存
- 高画質のサムネイル画像をダウンロード
- WebP 形式でのサムネイルを取得

::: tip ヒント
maxresdefault（最大画質）は、すべての動画で利用可能とは限りません。動画によっては、低解像度のサムネイルのみ存在する場合があります。
:::
